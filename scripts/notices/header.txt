burnwright: third-party notices
===============================

burnwright is free software under the GNU General Public License, version 3
or any later version. The licence is in LICENSE.txt next to this file
(LICENSE in burnwright's source).

burnwright is built from other people's work. This file lists what is
compiled into the burnwright program itself, with the licence each author
chose:

  1. Rust crates, for every platform burnwright ships on. Some of them are
     only in the build for one platform.
  2. JavaScript packages in the user interface.

Some crates carry a C library and compile it in. Each is listed under the
crate that carries it:

  liblzma-sys   liblzma, from XZ Utils       https://tukaani.org/xz/
  lzfse-sys     LZFSE, from Apple            https://github.com/lzfse/lzfse
  zstd-sys      Zstandard, from Meta         https://github.com/facebook/zstd

The copies of minipro that burnwright installs beside itself, and the libusb
and zlib built into them, are separate programs. Their licences and a
NOTICE.txt are in the "minipro" and "minipro-t76" folders next to this file.

Where the source is. A few crates are under the Mozilla Public License 2.0,
which asks that you be told where to get their source. Every Rust crate
listed here is published at https://crates.io/crates/<name>, at the version
recorded in the Cargo.lock of the burnwright release you have:
https://github.com/IamMrCupp/burnwright. burnwright uses all of them
unchanged.

Many crates share one licence text. Where a crate ships its own copy, with
its own copyright line, that copy is the one printed.

This file is generated by scripts/notices/generate.sh in burnwright's source.
